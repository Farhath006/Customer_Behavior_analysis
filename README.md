## Customer Behavior Analysis
### Overview
This project analyzes customer shopping behavior using data analytics techniques to identify purchasing trends, customer preferences, and business insights.
The project was developed using Python, MySQL, and Power BI for data processing, analysis, and visualization.
## Objectives
- Analyze customer purchasing patterns
- Identify trends based on age, gender, and category
- Study seasonal shopping behavior
- Understand the impact of discounts and promo codes
- Create interactive dashboards for business insights
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- MySQL
- Power BI
- Jupyter Notebook
## Dataset Features
### The dataset includes:
- Customer ID
- Age
- Gender
- Item Purchased
- Product Category
- Purchase Amount
- Location
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Promo Code Usage
## Project Workflow
- Data Collection
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Customer Behavior Analysis
- Data Visualization
- Dashboard Creation
## Key Insights
- Clothing products showed high purchase frequency
- Seasonal trends influenced customer buying behavior
- Discounts and promo codes increased purchases
- Different age groups preferred different product categories
- Subscription users showed more frequent purchases
